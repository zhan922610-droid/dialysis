# AI Dialysis Diary — инструкция по запуску и сборке

Настольная программа для Windows: автоматическое формирование дневников гемодиализа
из карты диализных процедур (TXT) и шаблона дневника (TXT).
**Шаблон неизменяем, данные берутся только из карты, медицинские факты не выдумываются,
каждый дневник проходит проверку, копирование выполняется одним нажатием.**

---

## 0. Два варианта интерфейса и размер EXE

| Вариант | Файл | Зависимости | Размер бандла | Spec-файл |
|---|---|---|---|---|
| **Лёгкий (рекомендуется)** | `gui_tk.py` (tkinter) | нет (tkinter встроен в Python) | **~10–15 МБ → zip ~5–8 МБ** | `AIDialysisDiary.spec` |
| Красивый (PySide6) | `gui_qt.py` (Qt) | PySide6 | ~140 МБ → zip ~60 МБ | `AIDialysisDiary_Qt.spec` |

Функционально варианты полностью идентичны (одна общая бизнес-логика в `app/`,
одинаковые статусы, предупреждения, копирование, сохранение). Тёмная тема есть в обоих.
Если файл получается «слишком большим для загрузки» — используйте ЛЁГКИЙ вариант
и пересылайте его в ZIP-архиве (GitHub Actions ниже собирает сразу `.zip`).

Точка входа `main.py` сама выбирает интерфейс: если установлен PySide6 — запускается
Qt-версия, иначе — лёгкая tkinter-версия. В собранном лёгком EXE Qt отсутствует.

## 2. Самый быстрый способ получить маленький EXE (без установки Python)

GitHub Actions соберёт Windows-файлы сам:

1. Создайте репозиторий GitHub и загрузите в него все файлы проекта
   (размер исходников — десятки килобайт, лимиты не проблема).
2. Репозиторий уже содержит `.github/workflows/build.yml` — сборка запустится
   автоматически (вкладка **Actions**). Можно запустить и вручную:
   Actions → «Build Windows EXE» → **Run workflow**.
3. Через 3–5 минут в конце пробега (Artifacts) появятся два архива:
   - **AIDialysisDiary-Windows-light** — лёгкий EXE в ZIP (~5–8 МБ) ← качайте его;
   - **AIDialysisDiary-Windows-qt** — Qt-версия в ZIP (~60 МБ).
4. Распакуйте ZIP и скопируйте папку целиком на компьютер врача — запуск без Python.

## 3. Сборка EXE локально на Windows (повторная сборка)

### Вариант А — автоматически (рекомендуется)

1. Установите Python 3.10–3.12 с python.org (галочка «Add Python to PATH»).
2. Скопируйте проект, например в `C:\DialysisDiary` (путь без кириллицы и пробелов).
3. Дважды щёлкните `build_windows.bat` — готово: `dist\AIDialysisDiary\AIDialysisDiary.exe`
   (лёгкий, ~10 МБ). Для Qt-версии — `build_windows_qt.bat`.

### Вариант Б — вручную

```bat
cd C:\DialysisDiary
python -m pip install pyinstaller
pyinstaller AIDialysisDiary.spec --clean --noconfirm
```

Для Qt-версии:

```bat
python -m pip install -r requirements_qt.txt
pyinstaller AIDialysisDiary_Qt.spec --clean --noconfirm
```

### Как уменьшить размер ещё сильнее

- **ZIP-архив**: упакуйте `dist\AIDialysisDiary` в zip — для передачи/загрузки
  это в 2–3 раза меньше (самый простой способ решить проблему «весит много»).
- **UPX**: установите UPX и добавьте `upx=True` в spec — минус ~30 % размера.
- **One-file**: замените в `AIDialysisDiary.spec` у `EXE(...)` параметр
  `exclude_binaries=True` на `False`, передайте в `EXE` списки
  `a.binaries, a.zipfiles, a.datas` и удалите блок `COLLECT` — получится один
  `AIDialysisDiary.exe` (~15 МБ). Запускается чуть медленнее (распаковка при старте).

Значок приложения: положите `app.ico` в корень проекта и укажите `icon='app.ico'` в spec.

> Примечание: `.exe` может быть собран только на Windows (PyInstaller не выполняет
> кросс-компиляцию). В Linux-среде разработки выполнена контрольная сборка и запуск
> обоих бандлов для проверки целостности кода.

## 5. Как пользоваться

1. Откройте `AIDialysisDiary.exe`.
2. Нажмите **«Загрузить карту диализных процедур»** и выберите TXT-файл карты.
3. Нажмите **«Загрузить шаблон дневника»** и выберите TXT-файл шаблона.
   Файлы можно перезагрузить в любой момент — они будут заменены.
4. Нажмите **«Сформировать дневники»**. Программа разберёт карту по сеансам,
   подставит в шаблон только разрешённые поля (АД, ЧСС, течение диализа,
   назначения, заместительная терапия, веса, дата/время) и проверит каждый
   дневник по регламенту.
5. Слева — список сеансов в хронологическом порядке с цветовой меткой статуса:
   - 🟢 **Готов** — все данные на месте, противоречий нет;
   - 🟡 **Требует проверки** — есть пропуски/несостыковки, перед копированием
     программа покажет предупреждение;
   - 🔴 **Ошибка** — дневник нельзя достоверно сформировать; тихое копирование
     заблокировано.
6. Выберите сеанс — справа появится полный текст дневника. Кнопки:
   **«Копировать дневник»**, **«Сохранить в TXT»**, **«Показать предупреждения»**,
   а также **«Копировать все дневники»** и **«Сохранить все в TXT-файлы»**
   (имена вида `03.10.2026_Сеанс_2.txt`).
7. Вставьте текст в МИС «Надежда». Исходные файлы карта/шаблон не изменяются.

Все данные обрабатываются локально; интернет и внешние ИИ-сервисы не используются.

## 6. Требования к входным файлам

- **Карта**: TXT в UTF-8, UTF-8 BOM или Windows-1251. Парсер устойчив к разным
  вариантам форматирования; если значение нельзя однозначно отнести к сеансу, оно
  НЕ переносится в дневник — вместо этого показывается ошибка с указанием поля и даты.
- **Шаблон**: TXT с разделами «Жалобы», «Объективно», «Способ подключения» и т.д.
  Текст разделов переносится дословно. Если обязательное поле в шаблоне отсутствует
  или структура неоднозначна — программа предупредит и запросит исправление шаблона.
- Программа никогда не придумывает АД, ЧСС, веса, симптомы и результаты лечения,
  не переписывает формулировки шаблона и не исправляет противоречия самостоятельно.

Примеры корректных файлов — в папке `examples/`.
